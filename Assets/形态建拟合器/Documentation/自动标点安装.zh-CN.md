# 可选自动标点安装

手工描边/标点和所有拟合功能不要求 Python。此文仅用于启用本地自动候选检测。自动结果确认后才进入拟合，遮挡位置仍需检查。

发行包提供脚本，**不捆绑 Python、pip 依赖或检测模型权重**。以下命令在 Unity 工程根目录运行，需要本机安装 Python 3.12。安装阶段访问包索引及官方模型来源；检测阶段使用本地文件。

## 二次元：YOLOv3 + HRNetV2，最多 28 点

```powershell
py -3.12 -m venv Library/形态建拟合器自动标点/.anime_auto_venv
Library/形态建拟合器自动标点/.anime_auto_venv/Scripts/python.exe -m pip install torch==2.14.1+cpu torchvision==0.29.1+cpu --index-url https://download.pytorch.org/whl/cpu
Library/形态建拟合器自动标点/.anime_auto_venv/Scripts/python.exe -m pip install -r Assets/形态建拟合器/Tools/AutoLandmarks/requirements-anime-lock.txt
Library/形态建拟合器自动标点/.anime_auto_venv/Scripts/python.exe Assets/形态建拟合器/Tools/AutoLandmarks/setup_anime_models.py --output-root Library/形态建拟合器自动标点/photo_auto_models/anime
```

依赖锁文件记录此前 Windows/Python 3.12 的可用环境，本次打包没有从网络重新安装全部依赖；目标平台缺少对应 wheel 时不要随意替换版本，先查依赖安装错误。

下载器只从 hysts 的固定 Hugging Face revision 获取两个 `model.safetensors`，读取仓库 LFS SHA256 并核对文件，再生成 `engine.json`；不是任意来源的 `.pth` pickle。两文件约 285 MB。

| 模型 | 固定 revision | SHA256 |
| --- | --- | --- |
| hysts/anime-face-detector-yolov3 | afdd4226a79ae8bb81f334dbcffd34f8cc000c38 | 23bbc708146bcbc1c910f00fe152adbc70d7658d875a0121eaf4ee61d978b2c4 |
| hysts/anime-face-detector-hrnetv2 | 9b3435248b26aeb82e2a8578fe9d86d5d57158af | e71271376406a743c01528a0460637fcc06e72aeeea583f85007cc72dc8b7a4a |

在图片拟合窗口选择“二次元”，展开“自动标点设置”。默认路径如下；如果窗口中显示的路径不同，请手动指定对应文件：

| 字段 | 工程根目录下的位置 |
| --- | --- |
| Python | Library/形态建拟合器自动标点/.anime_auto_venv/Scripts/python.exe |
| 检测脚本 | Assets/形态建拟合器/Tools/AutoLandmarks/anime_photo_landmarks.py |
| 引擎模型配置 | Library/形态建拟合器自动标点/photo_auto_models/anime/engine.json |

检测器最多产生它支持的 28 点，不会为了凑齐 80 点插值补造。热图响应不是正确率或遮挡置信度；头发下的眼眉可能仍有高响应错误点。

## 真人：MediaPipe

```powershell
py -3.12 -m venv Library/形态建拟合器自动标点/.photo_auto_venv
Library/形态建拟合器自动标点/.photo_auto_venv/Scripts/python.exe -m pip install -r Assets/形态建拟合器/Tools/AutoLandmarks/requirements-mediapipe-lock.txt
```

从 [MediaPipe Face Landmarker 官方模型说明](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker#models) 获取官方 `face_landmarker.task`，放到 `Library/形态建拟合器自动标点/photo_auto_models/face_landmarker.task`。此步骤由使用者按官方来源完成；发行包不自动下载真人模型。

在窗口选择“真人”，Python 指向 `.photo_auto_venv/Scripts/python.exe`，脚本指向 `Assets/形态建拟合器/Tools/AutoLandmarks/photo_auto_landmarks.py`，模型指向上述 `.task` 文件。脚本入口锁定 MediaPipe 0.10.32。

## 本地文件与迁移

Unity 给检测进程传入当前显示图片的 PNG 副本，避免第二次 EXIF 旋转。每次任务在 `Library/PhotoAutoLandmarks/<编号>/` 保存 `input.png` 和检测结果。插件不把图片上传到 API；这些临时文件不会自动随任务完成删除，清理 Library 会同时清除它们。

新版本默认将检测环境放在 `Library/形态建拟合器自动标点`。Unity 工程迁移或清理 Library 后需要重建环境和下载模型；也可以把环境放在工程外，并在三条路径中指定。路径允许空格，插件用本地进程直接执行 Python，不经 shell。

模型文件缺失、哈希不符、无脸、多脸、超时或引擎切换时，当前正式标注保持；新候选不会静默覆盖手工点。多脸图请先裁剪为单人。
