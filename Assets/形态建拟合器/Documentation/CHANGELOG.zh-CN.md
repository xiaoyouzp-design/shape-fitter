# 0.2.0-preview.1 — 2026-10-19

- 修复 Unity 2022 Windows 导入中文包名时的临时 TAR 解压错误，实际导入复验通过。
- 发行目录、Unity 安装包、ZIP 和校验文件统一使用“形态建拟合器”名称；同步更新安装指引及构建验证脚本。包内目录改为 Assets/形态建拟合器，自动标点环境与生成目录同步中文化；安装器备份并迁移旧目录。内部类型与 GUID 保留，兼容既有工程和存档。
- 图片拟合、模型拟合、构建模型坐标、拟合存档使用独立中文菜单。
- 支持指定模型坐标档案；新拓扑可生成待检查候选，按模型名自动归档。
- 图片输入支持手工点、多段线描边、局部区域调整、100%–800% 缩放和平移。
- 42 基础点与 38 可选细分点；二次元自动候选最多 28 点，真人 MediaPipe 为可选入口。
- 描边拟合改为同部位分段有序轮廓匹配，各部位等权；加入以拟合开始前权重为中心的软先验。
- 输出分别展示二维偏差与先验，支持应用、动画、带预览的存档。
- 黄色投影默认隐藏，并提供图旁开关及说明。
- 本次发行适配：自动检测路径不再引用开发机目录，脚本随插件提供，运行环境默认位于工程 Library；安装脚本支持备份，提供文件清单和 SHA256 校验。

本版本仍为原型预览版。降低参数触边不代表照片还原精度已经得到证明；详见审计报告。
