# 升级与卸载

本文适用于已经安装过插件的工程。首次使用请直接阅读 [使用说明](使用说明.zh-CN.md)。

## 更新现有安装

先导出当前标注 JSON 并保存要保留的拟合存档。窗口内尚未保存的图片与预览可能在脚本重载后丢失。

关闭 Unity，解压完整 ZIP，在解压目录执行：

```powershell
.\Verify-Package.ps1
.\Install.ps1 -ProjectPath '你的 Unity 工程目录'
```

安装器会先将现有插件备份到工程根目录 `形态建拟合器备份/<时间>/`，再安装到 `Assets/形态建拟合器`。独立坐标库和存档库保留。重新打开 Unity，等待编译完成。

## 早期测试版本的目录迁移

如果工程中仍有早期的 `Assets/ModelCard`，上面的安装器会备份并迁移该目录及 `.meta`，保留额外文件。不要将新目录直接复制到旧目录旁，以免重复加载程序集。

如果使用 Unity 安装包更新，请先在 Project 窗口将旧目录改名为“形态建拟合器”，待资源刷新后再导入。新旧两个目录已经同时存在时，先保留备份并将多余版本移到 Assets 之外，再安装。

## 回退与卸载

回退时关闭 Unity，把当前插件目录和对应 `.meta` 移到工程外，再按备份中的原目录名恢复完整备份。

卸载时移走 `Assets/形态建拟合器` 及其 `.meta`。`Assets/形态键拟合` 下的坐标和存档可独立保留；存档资产需要插件脚本才能正常查看与操作。
