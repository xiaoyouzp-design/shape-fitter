# 来源与许可记录

本包为现有 VRC Model Card 源码及本项目形态键拟合扩展的发行快照。检查到原插件源码目录没有独立的根级开源 LICENSE；本次打包不替权利人新增 MIT/Apache 等授权。使用与再分发仍依现有权利约定。二维码编码器、PNG 卡片等基础代码保留原文件内容和注释，未在本轮重新进行独立来源鉴定。

人物网格、纹理、材质、VRM/FBX、参考图片、用户坐标存档、检测权重和 Python 环境均未捆绑。内置 Rurune/Plum 配置只有指定拓扑的索引、权重及指纹，不授予人物模型资产使用权。

可选依赖来自：

- [hysts/anime-face-detector](https://github.com/hysts/anime-face-detector)：实际适配 0.1.0；历史审阅源码 commit 为 `98a9fb480fa04bdd96acbe4d98da191a898267f3`。主体 MIT，衍生 OpenMMLab 部分 Apache-2.0。相关许可文本保留在 `third-party/`；上游实现代码和权重不在本包。
- YOLOv3、HRNetV2 作者模型仓库及固定 revision 见自动标点安装文档。历史模型声明为 MIT；下载时应同时保留上游许可信息。
- [MediaPipe](https://github.com/google-ai-edge/mediapipe)：可选外部依赖。官方模型的获取与许可按官方页面执行，本包不包含 `.task`。
- PyTorch、torchvision、Pillow、NumPy、OpenCV 等通过 pip 单独安装，其各自许可由相应发行包提供。
- Unity 和可选 VRChat SDK 使用各自许可，本包不提供编辑器或 SDK。

依赖版本锁文件是可复现环境记录，不等于对所有依赖完成了漏洞扫描或法律审查。
