# 形态建拟合器使用说明

版本：0.2.0-preview.2，2026-10-19。已验证 Windows / Unity 2022.3.22f1；其他 Unity 版本、macOS/Linux、URP/HDRP 未完成同等实测。

## 首次安装

1. 从 [下载页](https://github.com/xiaoyouzp-design/shape-fitter/releases/tag/v0.2.0-preview.2) 获取 `.unitypackage` 安装包。
2. 在 Unity 中导入安装包，等待脚本编译完成。插件目录为 `Assets/形态建拟合器`。
3. 在顶部“形态键拟合”菜单中选择“构建模型坐标”“图片拟合”“模型拟合”或“拟合存档”。

开始前准备一个带脸部形态键的模型。图片拟合还需一张参考图；模型间拟合需另一个参考模型。手工标注与拟合无需 Python，自动标点依赖的安装方法见 [自动标点安装](自动标点安装.zh-CN.md)。

已经安装过插件时，按 [升级与卸载](升级与卸载.zh-CN.md) 操作。

## 先为模型建立坐标

1. 选择场景中模型根对象，打开 `形态键拟合 / 构建模型坐标`。
2. 选择实际承载脸部形态键的 SkinnedMeshRenderer。多个脸部网格不会自动合并。
3. 自动生成坐标并检查预览。已识别拓扑可复用配置；新拓扑生成的是候选，检查后才能用于拟合。
4. 检查眼角、上下眼睑、鼻尖、嘴部、脸廓和左右方向；检查候选键是否确实改变目标部位。
5. 坐标以“模型名＋网格名＋时间＋状态”自动归档到 `Assets/形态键拟合/模型坐标/`，后续修改自动保存。

包内 Rurune、Plum 配置是指定拓扑的索引/权重映射，不含人物网格。模型名称相同不代表拓扑相同；插件会检查指纹。当前求解范围为单脸部网格、单个正权重帧的线性形态键、0–100 权重。多帧或负权重形态键不在当前验证范围。

## 图片拟合

打开 `形态键拟合 / 图片拟合`，选择待调整模型、加载单人参考图。只标图片；模型端坐标来自前一步配置。

### 描边、标点与缩放

在“① 标记图片”中选择部位与工具：

| 工具 | 操作 |
| --- | --- |
| 描边 | 沿轮廓连续点击画折线；双击/回车预览；检查后“采用这条轮廓” |
| 拖动 | 拖动标注点，或拖动已有轮廓线段调整两端 |
| 区域 | 移动/缩放所选部位已有标注 |
| 补点 | 选择该部位的局部点名并点击图片；不可见点可跳过 |
| 删除 | 点击已有点删除；支持撤销 |

眼睛沿**眼睛开口边缘**圈一圈，不沿睫毛尖或眼影。嘴部沿**上下唇开口边缘**，不沿外唇缘；嘴闭得很细时使用单点补标。眉毛沿中线开放描绘。脸廓从一侧脸颊经下巴到另一侧，不画额头、不封口。鼻尖只点一次。左右按**画面左右**。

描边时右键/Backspace 退一个折点；Esc 取消拖动或清除该部位草稿。切换部位保留草稿；更换图片清除草稿。橙色折线是草稿，紫点是采样预览，采用后才变成正式输入。采用只替换当前部位，支持一次撤销。还有未采用草稿时不能开始拟合；未采用草稿也不会随标注导出。

图内滚轮以鼠标位置为中心缩放，中键或 Alt＋左键平移；“适应窗口”复位。显示缩放范围为 100%–800%，标注始终存为原图归一化坐标。

青点是图片标注；可选的黄色点/黄线表示模型匹配及偏差，不是新增标注。黄色层默认隐藏，图片上方可打开“显示拟合偏差”。

### 拟合与输出

点击“开始拟合并预览”。当前使用 5 个初值，按二维匹配与权重先验的总目标选解，不能证明全局最优。描边在同部位、同一上下弧内有序匹配，各部位总权重相同。未描边的单点保留明确语义对应。

“② 查看结果”提供前后、单独前/后和差异预览，并显示部位均衡二维偏差、二维损失与先验代价。先验以**本次开始前的模型权重**为中心，不是从照片恢复出的通用默认值。参数详情显示触边和多初值范围；范围不是置信区间。

- **应用到模型**：将当前结果写入选中模型，可撤销。
- **保存为动画**：生成 `.anim`；可保存静态姿态，或从拟合前过渡到拟合后。绑定路径相对于所选模型根对象。
- **保存拟合存档**：生成 `.asset`，包含结果、配置、原标注和预览；通过 `形态键拟合 / 拟合存档` 查看，之后再应用或导出动画。

拟合预览会恢复场景模型原权重，只有点击应用才保留到模型。若结果不合适，不要靠增加重复点来加压；先检查对应部位、遮挡、模型坐标与参数可表达范围。

## 模型间拟合

打开独立的 `形态键拟合 / 模型拟合`，分别选择参考模型和待调整模型，加载各自已检查的坐标档案，再拟合预览。两模型通过共同几何特征比较，**不是把某个模型的原生权重数字直接复制给另一模型**。结果同样支持应用、动画与存档。

自动构建可为新模型生成候选坐标，但须检查。它不代表任意模型都能自动可靠识别，也不保证目标模型现有形态键能够表达参考模型的脸型。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 没有菜单或出现编译错误 | 检查 Console 第一条错误，确认完整导入且没有重复安装插件；验证版本为 Unity 2022.3.22f1 |
| 模型坐标无效/指纹不符 | 选择正确脸部网格，重新为该拓扑构建坐标；不要只修改配置中的模型名字 |
| 黄色点偏移 | 它是拟合残差，不是人工点移动；先看颜色说明和偏差指标 |
| 描边后无法拟合 | 采用或清除所有部位的草稿；轮廓交叉、过短、方向不明时先修正 |
| 自动标点文件缺失 | 按自动标点安装文档配置 Python、脚本、模型三条路径；手工模式仍可用 |
| 已检测但原点没变化 | 自动候选要先确认，确认只补充未标点，不覆盖手工点或已跳过点 |
| 参数达到 100 或外观不像 | 检查轮廓对应与模型表达范围；二维误差降低不等于权重正确 |

单图仍难约束鼻、嘴、下巴的深度、三维转头及遮挡区域。当前不使用整图像素损失去拟合发型、光照、材质或妆容。结论限于指定模型和指定坐标映射，不构成任意 VRM 或任意真实照片都能可靠恢复的保证。
